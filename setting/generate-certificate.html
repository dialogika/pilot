Panduan Batch Input

Gunakan format yang konsisten agar proses import dan export ZIP berjalan mulus.

Langkah Pakai
  1. Isi `Tanggal Global Sertifikat` terlebih dahulu bila sebagian baris tidak memiliki tanggal sendiri.
  2. Tempel data peserta, satu peserta per baris.
  3. Klik `Import Batch`, cek jumlah valid/invalid, lalu review preview peserta aktif.
  4. Pilih format export batch (`SVG`, `PNG`, atau `Keduanya`) sebelum klik `Download Batch ZIP`.
Aturan Format
  • Setiap baris minimal berisi `invoice`, `nama peserta`, dan `kelas`.
  • Kolom keempat `tanggal` bersifat opsional, formatnya `DD/MM/YYYY`.
  • Pemisah yang didukung: `TAB`, `|`, atau koma `,`.
  • Baris kosong diabaikan, baris invalid tidak ikut diproses.
Contoh Format Valid
13.07353	Asih Wulansari	Public Speaking Basic
13.07354	Budi Santoso	Public Speaking Advanced	20/04/2026
13.07355|Citra Lestari|Public Speaking Basic|21/04/2026
13.07356,Daniel Pratama,Public Speaking Advanced,22/04/2026

Format per baris: invoice + nama + kelas + tanggal opsional. Separator bisa TAB, koma, atau pipe.
